# Culture Shift

A 12 to 15 minute browser game about security awareness and culture.

You've just been put in charge of the human side of security at your company. You have a year and a limited budget. Leadership wants a training completion number, and attackers don't care about that number. Decide how people are trained, how they report, what happens when someone clicks, and how to handle the pressures that arrive along the way. Then something real happens, and you find out what you built.

**Play it:** https://jckesler.github.io/culture-shift/

## What it covers

- Awareness training that changes behavior versus training that produces a completion number
- Reporting: a report button, a response, and recognition
- Making the secure way the easy way (security fatigue, passwords, passkeys)
- Simulated phishing tests: what they measure, what they cost in trust, and how to run them if a customer or insurer requires them
- Psychological safety and what happens when people are shamed for mistakes
- Leadership exceptions, employee monitoring, shadow AI and privacy culture
- Verification habits against impersonation and deepfakes

Each play draws one of three invented companies (a health system, a retailer and a software vendor). The debrief includes a click-rate reveal showing how much of the number leadership watched depended on which test email was sent. It can be downloaded as a PDF with an optional name and a run code. Pasting the run code into "Check a result" on the start screen rebuilds that exact year, so an instructor can check a submitted PDF in a few seconds.

## Running it

It's a single self-contained HTML file. Open `index.html` in any modern browser, or host it anywhere that serves static files. No build step, no server, no data collected.
